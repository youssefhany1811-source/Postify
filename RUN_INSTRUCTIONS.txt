# Postify - Execution Instructions (Manual Setup for Windows)

Since Docker configuration is not present in the repository, follow these steps to run the application manually.

## Prerequisites
- PHP ^8.2 (with necessary extensions for Laravel)
- Composer
- Node.js & npm
- MySQL/MariaDB (or use SQLite as per Laravel default)

---

## 1. Backend Setup (Laravel)
1. Open a terminal and navigate to the backend directory:
   ```cmd
   cd backend
   ```
2. Install PHP dependencies:
   ```cmd
   composer install
   ```
3. Set up the environment file:
   ```cmd
   copy .env.example .env
   ```
4. Generate the application key:
   ```cmd
   php artisan key:generate
   ```
5. Configure your database in the `.env` file (DB_DATABASE, DB_USERNAME, DB_PASSWORD).
6. Run migrations:
   ```cmd
   php artisan migrate
   ```
7. Start the backend server:
   ```cmd
   php artisan serve
   ```
   The backend will be available at: http://localhost:8000

---

## 2. Frontend Setup (React)
1. Open a new terminal and navigate to the frontend directory:
   ```cmd
   cd frontend
   ```
2. Install npm dependencies:
   ```cmd
   npm install
   ```
3. Set up the environment file:
   ```cmd
   copy .env.example .env
   ```
4. Start the React development server:
   ```cmd
   npm start
   ```
   The frontend will be available at: http://localhost:3000

---

## 3. All-in-One Run Command (Recommended)
Once setup is complete, you can run both the backend and frontend with a single command from the root directory.

**For PowerShell (Standard Windows Terminal):**
```powershell
npx concurrently "cd backend; php artisan serve" "cd frontend; npm start" --shell powershell
```

**For CMD:**
```cmd
npx concurrently "cd backend & php artisan serve" "cd frontend & npm start"
```

---

## 4. Running Background Services (Optional)
If the application uses queues (e.g., for notifications), run:
```cmd
php artisan queue:work
```
Or for Laravel Horizon (as seen in composer.json):
```cmd
php artisan horizon
```

---

## Troubleshooting
- **Database:** Ensure your local database server is running before executing migrations.
- **Port Conflicts:** If ports 8000 or 3000 are occupied, Laravel and React will usually suggest alternatives.
- **Vite (Backend Assets):** If you need to compile backend assets (for Blade views), run `npm run dev` inside the `backend` folder.
